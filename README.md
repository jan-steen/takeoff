# Systematic review of habitat monitoring using unoccupied aerial systems

This repository contains data, scripts and figures used for the PRISMA scheme systematic review described in the research article "Systematic review of habitat monitoring using unoccupied aerial systems". 
The R-project should be opened via [takeoff.Rproj](takeoff.Rproj) to ensure the proper relative file paths. Following content can be found in the underlying folders: 

- [data:](data) Contains a folder used for the article [screening](screening) process, with preliminary and final search strings and their results. .bib files for abstract and full text screening are also given. The [data_extraction](data_extraction) folder contains the decisions for exclusion during full text screening as well as the authors data extraction files and a combined final data extraction file used in subsequent analysis.
- [script:](script) Contains all R-scripts developed for this study, including the analysis of keywords, which was supported by the litsearchR R-package, and all scripts for analysis and visualisation of the data extracted from the reviewed articles.
- [figures:](figures) Contains final visualisations used for the scientific review as .pdf files.
